Praktik Komputer

Latihan keterampilan digital melalui panduan sederhana. Pilih topik dan ikuti langkahnya.

PEMULA

📁 Mengelola File dan Folder

Latihan membuat folder, memberi nama file, menyalin, memindahkan, dan menyimpan dokumen dengan rapi.

  1. Buat folder bernama Latihan Informatika.
  2. Di dalamnya, buat folder Dokumen dan Gambar.
  3. Simpan satu dokumen latihan ke folder Dokumen.
PEMULA

⌨️ Mengenal Shortcut Keyboard

Gunakan kombinasi tombol untuk bekerja lebih cepat.

  • Ctrl + C: menyalin
  • Ctrl + V: menempelkan
  • Ctrl + Z: membatalkan tindakan
  • Ctrl + S: menyimpan
  • Windows + L: mengunci komputer
KREATIF

🌐 Membuat Halaman Web Pertama

Kenali struktur HTML melalui proyek halaman sederhana. Mulai dengan elemen judul, paragraf, tautan, dan gambar.

Guru dapat menambahkan lembar kerja, tautan simulasi, atau video demonstrasi pada setiap kegiatan praktik.
